# Recursion-Bounded & Overflow-Safe Binary TLV Decoder (`checked_tlv_parser`)

> Category: **Safe Parsing** | Language: **C11**

## Overview

Decodes binary Type-Length-Value frames enforcing strict remaining-buffer checks against SIZE_MAX integer wraparound, truncated payloads, and nested container recursion limits.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N)` |
| **Space Complexity** | `O(D)` |

## Mathematical & Safety Invariants

- Cursor advances monotonically without ever reading past buffer + total_len.
- Constructed nested TLV frames abort cleanly above max_depth.
