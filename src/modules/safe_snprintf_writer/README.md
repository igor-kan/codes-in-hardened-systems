# Truncation-Safe Append Cursor & Bounded Format Writer (`safe_snprintf_writer`)

> Category: **Safe String Handling** | Language: **C11**

## Overview

Maintains a bounded write cursor over caller-owned buffers that never suffers snprintf negative-return or overflowed remaining-bytes UB, always preserving trailing NUL termination and latching sticky truncation flags.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N)` |
| **Space Complexity** | `O(1)` |

## Mathematical & Safety Invariants

- buf[cap-1] or buf[cursor] is guaranteed NUL-terminated when cap > 0.
- Sticky truncated flag remains set once capacity is saturated.
