# UB-Free Signed Narrowing & Checked Integer Arithmetic (`signed_checked_narrowing`)

> Category: **Arithmetic Hardening** | Language: **C11**

## Overview

Provides portable signed-overflow-free checked addition, multiplication, signed-to-unsigned/narrowing conversions (i64 -> i32, i64 -> size_t), and power-of-two pointer alignment without invoking C11 signed overflow UB.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(1)` |
| **Space Complexity** | `O(1)` |

## Mathematical & Safety Invariants

- Every widening or narrowing conversion rejects loss of magnitude or sign flip.
- Signed overflow detection executes purely using well-defined bounds comparisons or unsigned arithmetic.
