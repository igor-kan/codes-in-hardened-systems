# Borrow-Free Unsigned Sub & Saturate Guard Arithmetic (`checked_sub_u64_d59`)

> Category: **Integer Overflow Guard** | Language: **C11**

## Overview

Prevents silent uint64 underflow wraparounds during subtraction and clamps saturating subtraction safely to zero.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(1)` |
| **Space Complexity** | `O(1)` |

## Mathematical & Safety Invariants

- Underflow queries reject exact subtraction while saturating safely to 0.
