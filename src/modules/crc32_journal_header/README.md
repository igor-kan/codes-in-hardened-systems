# Hardened Little-Endian Wire Header & Payload CRC32 Validator (`crc32_journal_header`)

> Category: **Protocol & Serialization Hardening** | Language: **C11**

## Overview

Serializes and validates strict versioned binary headers (magic, version, bounded payload_len, header/payload IEEE CRC32) rejecting truncated or unaligned-overflow frames before allocation.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N)` |
| **Space Complexity** | `O(1)` |

## Mathematical & Safety Invariants

- Single-bit corruption anywhere in header or payload triggers ERR_INVARIANT.
- Frames claiming payload_len > max_allowed are rejected before inspecting payload bytes.
