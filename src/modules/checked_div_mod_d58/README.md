# Safe Checked Signed Int64 Division Rejecting Traps (`checked_div_mod_d58`)

> Category: **Undefined Behavior Prevention** | Language: **C11**

## Overview

Guards signed 64-bit integer division and modulo explicitly against both zero divisor and INT64_MIN / -1 signed overflow hardware traps.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(1)` |
| **Space Complexity** | `O(1)` |

## Mathematical & Safety Invariants

- Safe wrappers reject (x, 0) and (INT64_MIN, -1) while preserving exact quotients.
