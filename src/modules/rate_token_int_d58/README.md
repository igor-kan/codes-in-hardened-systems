# Fixed-Point Integer Credit Leaky-Bucket Limiter (`rate_token_int_d58`)

> Category: **Resource Quotas** | Language: **C11**

## Overview

Enforces deterministic event throughput quotas using overflow-safe integer timestamp increments cleanly avoiding floating-point drift.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(1)` |
| **Space Complexity** | `O(1)` |

## Mathematical & Safety Invariants

- Credits clamp cleanly inside [0, max_credits] across arbitrary timestamp steps.
