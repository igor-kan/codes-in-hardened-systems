# Clock-Skew & Integer-Overflow-Proof Monotonic Token Guard (`monotonic_rate_window_safe`)

> Category: **Resource & Denial-of-Service Hardening** | Language: **C11**

## Overview

Guards rate-limiters against backward clock jumps, saturating elapsed-nanosecond arithmetic, and capacity overflow using bounded integer fixed-point replenishment.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(1)` |
| **Space Complexity** | `O(1)` |

## Mathematical & Safety Invariants

- Available tokens remain tightly clamped within [0, max_tokens] under arbitrary timestamp regressions.
- Permitting N consumes exactly N tokens; denied requests leave token balance untouched.
