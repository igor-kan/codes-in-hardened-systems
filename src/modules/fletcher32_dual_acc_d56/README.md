# Fletcher-32 Modulo-65535 Integrity Checksum (`fletcher32_dual_acc_d56`)

> Category: **Checksums** | Language: **C11**

## Overview

Computes order-sensitive dual-accumulator Fletcher-32 digests over 16-bit word streams with zero-dependency modulo-65535 folding.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N)` |
| **Space Complexity** | `O(1)` |

## Mathematical & Safety Invariants

- Swapping two distinct adjacent words changes the Fletcher-32 checksum.
