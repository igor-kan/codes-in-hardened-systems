# Least-Privilege Monotonic Capability Bitmask State Machine (`privilege_cap_mask`)

> Category: **Access Control** | Language: **C11**

## Overview

Enforces monotonic least-privilege POSIX-style capability bounding sets ensuring Effective <= Permitted <= Bounding across all state transitions and denying any privilege re-escalation.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(1)` |
| **Space Complexity** | `O(1)` |

## Mathematical & Safety Invariants

- Invariant (effective & ~permitted) == 0 && (permitted & ~bounding) == 0 always holds.
- Any raise outside permitted/bounding fails atomically with zero partial mutation.
